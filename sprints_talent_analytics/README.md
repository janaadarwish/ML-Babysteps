# Sprints Talent Pipeline Analytics

Data pipeline and interactive dashboards that turn raw 2023 cohort assessment data into an employer-ready view of graduate skills, built for Sprints' Employer Partnerships team. Python stack only: NumPy, Pandas, Matplotlib, Seaborn, Plotly, PyGWalker.

## Project structure

```

├── data/
│   ├── raw/          sprints_cohort_data_2023.csv, employer_partner_requirements.json
│   └── processed/    generated by the pipeline
├── notebooks/
│   ├── 01_data_cleaning_and_eda.ipynb
│   ├── 02_feature_engineering_numpy.ipynb
│   └── 03_visualization_dashboard.ipynb
├── src/
│   ├── data_processor.py   cleaning, Skill_Mastery_Index, compatibility, reshaping

├── docs/                   charter, report, deck
├── assets/                 client_discovery_call.vtt, generated figures
└── README.md
```

## Setup

```bash
python -m venv .venv
source .venv/bin/activate        # Windows: .venv\Scripts\activate
pip install numpy pandas matplotlib seaborn plotly pygwalker jupyter
```

## Run

```bash
# 1. Full pipeline: cleans data, builds features, writes data/processed/
python src/data_processor.py

# 2. Static + interactive figures into assets/figures/
python src/visualizer.py

# 3. Collect the numbers used in the report and deck
python src/report_facts.py
```

Or open the notebooks in order (01 → 02 → 03). Every path is relative to the project root.

## What the pipeline does

| Step | Method |
|---|---|
| Cleaning | duplicate removal, out-of-range scores nulled, cohort-median imputation, IQR capping of engagement outliers |
| Skill_Mastery_Index | weighted average of the 10 module scores using NumPy ufuncs (no loops) |
| Employer fit | learner or cohort profile matrix times requirement matrix, cosine similarity via `np.linalg` |
| Time view | `melt` to long format, modules placed on a 12-month program timeline |
| Summary | `groupby` + named aggregation: median SMI and engagement by cohort and demographic |
| Visuals | colourblind-safe (Okabe-Ito) palette, no gridlines, Plotly hover and range slider, animated scatter, PyGWalker explorer |

## Key assumptions

- Module scores are on a 0–100 scale.
- Later modules carry more weight in the Skill_Mastery_Index (linear 1 → 2); change `default_weights` to adjust.
- The dataset has no per-module dates, so modules are spread evenly across 12 months.
- Requirement skills are matched to module columns by name or via `SKILL_TO_MODULE` in `data_processor.py`.

## Using the dashboards

- `assets/figures/dashboard.html` – open in any browser; hover for details, drag the range slider.
- `assets/figures/animated_scatter.html` – press Play to watch cohorts evolve.
- Notebook 03, last cell – PyGWalker drag-and-drop explorer for custom talent-pool searches.
